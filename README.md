# Stack Overflow Developer Survey Analysis 

An end-to-end exploratory data analysis (EDA) project inspecting the **Stack Overflow Developer Survey**, built with Python to extract key insights regarding developer demographics, programming language adoption, salary distributions, and remote work trends.

---

## 🚀 Project Overview
This project processes raw survey data to answer critical questions about the modern software development industry. It handles data cleaning (listwise deletion of missing values), statistical analysis of central tendencies, grouping aggregations, and automated multi-page PDF reporting.

---

## 📊 Key Findings & Insights
* **Python Dominance:** Python remains heavily adopted, showing exceptional popularity among younger developers (reaching ~71.8% in the 18–24 age group).
* **Compensation Trends:** Median and mean compensations vary significantly by country, with top-tier compensation observed in regions like the United States, Switzerland, and Israel.
* **Remote Work & Industries:** High-earning remote professionals (top 25% by income) are predominantly concentrated in core Software Development, Fintech, and Healthcare sectors.
* **Learning Pathways:** Online courses play a massive role in modern developer education, utilized by over 10,000 respondents in the dataset.

---

## 🛠️ Technologies & Libraries Used
* **Python 3.11** – Core programming language
* **Pandas & NumPy** – Data manipulation, cleaning, and aggregation
* **Matplotlib & Seaborn** – Data visualization and multi-page PDF generation (`PdfPages`)
